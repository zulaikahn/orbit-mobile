ORBIT MOBILE — WEB PREVIEW 0.1.0

This is a phone-first web app for iPhone Safari and Android Chrome.
It is separate from the Windows desktop build. No desktop helper is included.

Included: TV/movie catalogue search, seasons and episodes, local watchlist,
local progress and settings, install-to-home-screen guidance, a playable open
movie test, and direct HTTPS MP4/HLS playback where the phone/provider allows it.

Not included: a torrent engine, conversion server, DRM integration, a licensed
TV subscription, cloud accounts/sync, an Android APK or an iOS App Store binary.
Catalogue availability does not guarantee playable video.

Hosting: upload the contents of this folder to an HTTPS static host.
GitHub Pages can host it. All paths are relative and work beneath a project URL.
The service worker caches only the app shell, not shows, external APIs, or videos.
An internet connection is required for searching and watching.

On iPhone: Safari > Share > Add to Home Screen.
On Android: Chrome menu > Install app / Add to Home screen.
There is no claim of testing on physical iPhone or Android hardware yet.
